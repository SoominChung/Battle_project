# Battle_project

<배틀 동작 시나리오>
1. 플레이어 2명이서 한 쪽의 hp가 0 미만이 될 때 까지 싸운다. 
2. 서로 돌아가면서 각자의 공격을 행한다. 
3. 캐릭터마다 가질 수 있는 무기, 그 무기에 대한 사용방식, 특징적인 공격방법이 다르므로     Player 클래스를 추상 클래스로 만든 후에 서브클래스에서 메소드를 오버라이딩 시킨다.
4. 각 캐릭터는 ArrayList로 만들어진 무기창고를 갖는다. 갖는 무기의 개수는 플레이어를 생성시킬 때 설정해준다.(주먹& 특정 캐릭터 기본 무기 제외 개수). 개인의 무기창고는 메인에서 만들어진 전체 무기창고로부터 나온다. (만약 해당 캐릭터가 이용이 불가능한 무기가 배정되면 재배정 받음)
5. 주요 무기가 있는 특정 캐릭터에게는 해당 무기가 기본으로 하나는 배정된다. (ex: 토르: 토르 스페셜 망치/ 호크아이: 호크아이 스페셜 활)
6. 주먹은 모든 캐릭터에게 기본으로 하나가 배정된다. 
7. 캐릭터가 각 차례마다 공격을 하게 되는 방법은 두 가지이다. ① ‘공격하기’버튼을 눌러서 랜덤하게 공격: 1. 자신의 무기창고에서 무기를 랜덤으로 선정 2. 그 무기를 자신이 사용할 수 있는 방법을 이용하여 공격 (만약 총/화살로 공격을 시도하였으나 총알/화살 다 떨어지면 그 차례에 공격하지 못하고, 해당 무기는 무기창고에서 버려진다.) ② ‘무기 창고’버튼을 눌러서 갖고 있는 무기 중에 직접 골라서 버튼을 눌러 공격
8. 각 캐릭터의 attack 메소드는 무기에 따라 정의되어있다.
9. 무기를 가지고 공격을 할 때는 해당 무기의 기본 power + 각 캐릭터의 무기를 사용할 수    있는 능력치 power가 더해져서 사용된다.
10. 캐릭터의 기본 속성인 power는 주먹의 능력치를 뜻한다. 

<등장인물, 무기 기능& 속성 소개>

Player 하위 클래스 (캐릭터들) : 헐크, 호크아이, 블랙위도우, 토르, 아이언맨
1. 헐크 implements hittable(>주먹), throwable(>활,총,칼)
hp 500
power 80

사용 무기: 활, 총, 칼
사용 방법: 던지기 (추가 능력치: 50) 

사용불가 무기: 망치

2. 호크아이 implements hittable(>주먹), shootable(>활)
hp 400
power 20 (주먹)
호크아이 스페셜 활 (화살: 4)

사용 무기: 활
사용 방법: 활쏘기 (추가 능력치: 80) 
사용불가 무기: 총, 칼, 망치 

3. 블랙위도우 implements hittable(>주먹), shootable(>총), useable(>칼)
hp 500
power 100 (주먹)

사용 무기: 총, 칼
사용 방법: 총 쏘기 (추가 능력치: 20) , 칼 쓰기 (추가 능력치: 20)

사용불가 무기: 망치, 활 

4. 토르 implements hittable(>주먹) useable(>망치,칼)
hp 500
power 60 (주먹)
토르 스페셜 망치 (power: 140)
술마시기
최후필살기

사용 무기: 망치, 칼, 술마시기, 최후필살기
사용 방법: 망치질 (추가 능력치: 90), 최후 필살기 (능력치: 150. 최후 필살기의 능력치는 토르의 기본 파워에 추가되는 것이 아니라 최종 능력치 자체가 150임), 칼 쓰기 (추가 능력치: 10), 술마시기 (알콜중독돼서 자신의 hp -10)

사용불가 무기: 총, 활 


5. 아이언맨 implements hittable(>주먹), shootable(>총)
hp 400
power 50 (주먹)
아이언빔
슈트오작동

사용 무기: 총, 아이언빔, 슈트오작동
사용 방법: 총 쏘기, 아이언빔 (능력치: 100, 아이언빔의 능력치는 아이언맨의 기본 파워에 추가되는 것이 아니라 최종 능력치 자체가 100임), 슈트 고장 (자기 hp –40)  

사용불가 무기: 칼, 망치, 활
